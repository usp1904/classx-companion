\# CI/CD Pipeline



\## Purpose

Automate builds, testing, and deployments for the AI Companion MVP.



\## Tools

\- GitHub Actions / GitLab CI / Open‑source CI/CD runners



\## Stages

\- \*\*Build\*\*: Compile, lint, run unit tests

\- \*\*Test\*\*: Integration tests, pedagogy validation, performance checks

\- \*\*Deploy\*\*: Push to staging → production (via Docker/Kubernetes)

\- \*\*Monitor\*\*: Logs, alerts, rollback triggers

\- \*\*Syllabus Sync\*\*: Scheduled job to auto‑ingest latest syllabus updates (NCERT, CBSE, AP State Board, Telangana State Board) for Academic Year 2026‑27 and beyond.



\## Best Practice

Keep MVP pipeline minimal, expand as product scales.
